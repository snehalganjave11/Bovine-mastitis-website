# 🐄 AI-Based Early Forecasting of Bovine Mastitis

## 📌 Project Description

This project is a web-based platform for **AI-based predictive modelling and early forecasting of bovine mastitis in Indian dairy farms**. The system is designed to monitor important cattle health and milk-related parameters and identify the risk of mastitis at an early stage.

The website provides an interactive interface for farmers and dairy managers to view cattle information, monitor health parameters, assess mastitis risk, and understand the benefits of early disease detection.

## ✨ Features

* 🐄 Smart dairy cattle monitoring
* 🧠 AI-based mastitis risk prediction interface
* 🌡️ Body temperature monitoring
* 🥛 Milk yield monitoring
* ⚡ Milk conductivity monitoring
* 🔬 Somatic cell count monitoring
* 🐾 Activity-level monitoring
* ⚠️ Early mastitis risk identification
* 📊 Herd dashboard
* 📱 Responsive and user-friendly design

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* Responsive Web Design

## 🎯 Objective

To develop a simple and intelligent digital solution that supports **early detection of bovine mastitis**, helping dairy farmers take timely preventive action and improve cattle health and dairy farm management.

## 🚀 Future Scope

The frontend can be integrated with a machine-learning model, IoT sensors, database, and real-time farmer notification system to provide actual mastitis prediction and monitoring.
